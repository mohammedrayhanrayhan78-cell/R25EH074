02. Featured Projects

Flagship — GenAI / RAG

LexiRAG — Legal AI Assistant

A RAG-based legal document assistant with a hybrid inference setup: local Ollama + Gemma 2B for offline use, with Groq and Gemini APIs as cloud fallbacks, plus regional language support. Deployed on Azure.

  • Had a senior developer and a cybersecurity specialist stress-test the live demo — they found real security gaps
  • Hardened it in response: XSS sanitization, magic-byte file validation, authentication, rate limiting, environment variable management
  • Evolved from an earlier Streamlit prototype (legal-rag-india) that hit memory limits on free-tier hosting — rebuilt the retrieval layer around a lightweight numpy-based similarity search to remove the torch dependency
Python RAG Ollama / Gemma 2B Groq & Gemini APIs Azure Security Hardening

Hand-Tracking Virtual Steering Wheel
